# OpenVision

> かつて自分が見たものを、もう一度見る。許可のもとで、他者が見たものも見る。

OpenVision は、信頼できる一人称視点の体験メディア――記録、再生、非公開共有、来歴――のためのオープンソース・イニシアチブです。

## なぜ OpenVision なのか？

現在のメディアは画像を保存できても、個人の体験に意味を与える視点、文脈、信頼情報を失いがちです。また、記録が一つのデバイス、アプリケーション、アカウントに閉じ込められることもあります。

OpenVision は、より人間中心の道を探ります。自分の視点から大切な瞬間を残し、後で振り返り、意図した相手と共有し、そのメディアがどこから来てどう変わったかを理解できるようにすることを目指します。

本プロジェクトは、意識の再現、視覚的記憶の読み取り、あるいはあらゆるメディアが「本物」か「偽物」かを判定できるとは主張しません。

## 目指すもの

- **記録：** 明確な出自情報を伴う一人称視点の記録を作成する。
- **再生：** 対応するデバイスやアプリケーションで体験を振り返る。
- **非公開共有：** 技術的に可能な範囲で、個人メディアにアクセスできる相手と期間を選ぶ。
- **来歴：** 出自と変換に関する理解しやすい情報を保持する。
- **可搬性：** 一つの提供者に恒久的に依存せず、記録を保持・移動できるようにする。

OpenVision は設立初期の段階です。これらは公開された目標であり、安定した仕様や本番運用可能な実装があるという主張ではありません。

## 信頼モデル

検証可能な来歴は、万能な AI 偽物検出ではありません。OpenVision は三つの上位状態を用います。

- **検証済みの記録：** 参加システムが、宣言された記録の出自と自らが証明する履歴を検証できる。
- **宣言済みの合成または拡張：** 合成、生成、再構成、または実質的に拡張されたコンテンツを明示する。
- **来歴不明：** 出自または履歴を十分に検証できない。不明であることは偽物であることを意味しない。

来歴は、具体的で検査可能な主張を支えます。文脈、同意、報道、人間の判断に代わるものではありません。

## 原則

- 人間の主体性、尊厳、アクセシビリティを最優先する。
- プライバシーと意味のある同意を製品の基盤にする。
- 非公開を初期設定とし、理解しやすい操作を優先する。
- 元の素材と、合成または拡張された派生物を区別する。
- 記録の可搬性を保ち、信頼に関する主張の限界を正直に示す。
- 独立した製品やプロプライエタリ製品と共存できるオープンな基盤を築く。

## 方向性を示すロードマップ

1. **基盤：** 共通語彙、倫理、ガバナンス、相互運用の目標を整える。
2. **記録と再生：** 一人称視点の記録を作成し、振り返るための実用的な道筋を提供する。
3. **非公開共有：** 選択的アクセス、可搬性、透明な取り扱いを改善する。
4. **エコシステム：** 実装間の相互運用を可能にし、将来的にオープンで分散型の参加を広げる。

進展は、技術力だけでなく、実証された利用者価値、安全性、プライバシー、信頼性に基づきます。

## オープンな協働

OpenVision は、公開提案、研究、文書、リファレンス作業、批判的レビューを歓迎します。共有インターフェースと信頼原則により、オープンソース、商用、プロプライエタリの各実装が同じエコシステムに誠実に参加できることを目指します。
